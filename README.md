# aiXis Studio Homebrew Tap

Homebrew formulae/casks for aiXis Studio apps.
Formules et casks Homebrew pour les apps aiXis Studio.

## Snitch

```bash
brew install --cask --no-quarantine aixisstudio/tap/snitch
```

EN: `--no-quarantine` skips the Gatekeeper prompt — Snitch is ad-hoc signed,
not notarized. First launch asks for your admin password once (packet
capture needs it, like tcpdump/Wireshark).

FR: `--no-quarantine` évite l'invite Gatekeeper — Snitch est signé ad-hoc,
pas notarisé. Le premier lancement demande le mot de passe admin une fois
(la capture de paquets l'exige, comme tcpdump/Wireshark).
